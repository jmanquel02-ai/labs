# Labs - Ruleta POO

Repositorio correspondiente al desarrollo progresivo del proyecto **Ruleta** para la asignatura de Programación Orientada a Objetos.

El proyecto fue construido por iteraciones, incorporando gradualmente conceptos como separación de responsabilidades, MVC, relaciones entre clases, historial, estadísticas, herencia, polimorfismo, interfaces y persistencia.
